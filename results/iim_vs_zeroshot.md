# IIM baseline vs zero-shot：逐 OOD 数据集对照

- IIM：**w0（`DIVMEAN_W=0`）**，4-shot 与 16-shot 各 3 个随机种子的 mean ± std
- zero-shot：无训练、无随机性，故不给 std（ZeroShot trainer 不计算 JS / Spatial，只有 4 条分数）
- 指标：**FPR@95TPR（%↓） / AUROC（%↑）**，同 seed/同 split 口径
- 4 集平均：IIM 先每 seed 在 4 集上平均再跨 seed；zero-shot 为其日志的 4 集平均（已剔除 Easy/Hard 日志里多评的 第 5 个 ImageNet 集）
- ⚠️ **zero-shot 与 shot 数无关**，故 4-shot 块与 16-shot 块里的 ZS 列重复出现同一组数，便于逐行直接比对。

## 观察

1. **学习型 prompt 全面优于 zero-shot**：1k 上 `MCM 42.26 → S-MCM 23.46`，叠加空间项到 `20.98`；Hard 上 `48.59 → 29.29 → 26.88`；100 上 `30.18 → 11.42 → 9.39`。
2. **zero-shot 下 `S-MCM` 并非普遍优于 `MCM`**：4 集平均是好的（1k 42.26→37.12），但**逐集看是混合的** —— 1k/Texture 上 `MCM 57.29` 反而优于 `S-MCM 59.17`，Easy/Texture 上 `19.75 → 26.12` 明显变差。说明 `S-MCM` 的多 patch 打分需要先有**对齐良好的文本端**才成立，这正是学习型 prompt 的作用。
3. **论文里不能拿 zero-shot 的 `S-MCM` 当消融基线**——它本身就有退化。正确的对照是「学习型 prompt + `MCM`」→「+ `S-MCM`」→「+ JS & Spatial」。
4. **空间项在 Texture 上的收益最大且最稳定**：1k `37.36 → 31.48`、Hard `42.85 → 37.20`、100 `15.69 → 11.64`、Easy `11.24 → 10.02`；而在 SUN / places365 上只有 0.1~0.4 或基本持平。
5. 最难的两个集（Texture、places365）上 IIM 与 zero-shot 的差距反而最大，说明学习型 prompt 主要改善的是**难分布**上的判别力，而不是简单集。
6. **4-shot → 16-shot 全部单调改善**（4 集平均 FPR95，`S-MCM-JS-Spatial`）：1k `20.98 → 19.56`、Hard `26.88 → 24.68`、100 `9.39 → 8.23`、Easy `6.72 → 5.90`。但**空间项的绝对收益在 16-shot 下变小**（1k：4-shot 从 23.46 降 2.48，16-shot 从 21.77 降 2.21；100：−2.03 vs −1.41），与此前"训练侧改善与空间项部分冗余"的观察一致 —— 样本更多时基线本身已改善了局部证据结构。
7. 两个 shot 数下 **Texture 仍是空间项收益最大的集**（1k 4-shot −5.88 / 16-shot −5.24；Hard −5.65 / −5.41），说明该结论不依赖 shot 设置。
